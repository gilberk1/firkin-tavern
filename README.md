# Firkin Tavern Website Redesign

A UX case study and coded demo for Firkin Tavern, a restaurant and bar in Ewing, NJ. Created September to December 2015 during my graduate program at Philadelphia University.

## What I did

- Competitive research against Triumph Brewery's website
- Personas, a new sitemap, a user flow, card sorting, and user testing
- Wireframes tested with 10 users in the target group
- Visual designs in Photoshop with interaction states
- A coded, tablet- and mobile-responsive demo

## Built with

HTML, CSS, JavaScript
